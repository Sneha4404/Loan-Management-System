# 🏦 Loan Management System

A responsive Loan Management System built using HTML, CSS, and JavaScript.

---

## 📌 Project Overview

The Loan Management System allows users to:

- Register an account
- Login securely (Frontend)
- Apply for a loan
- View loan applications
- Edit loan details
- Delete loan applications
- Search loan applications
- View dashboard statistics
- View profile information
- Logout

The project currently uses **Local Storage** to store data. The backend using **Spring Boot** and **MySQL** will be integrated in the next phase.
